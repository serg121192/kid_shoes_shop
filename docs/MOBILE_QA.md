# Мобільне тестування — чеклист

Перевір на реальному телефоні (iOS Safari + Android Chrome), портрет і альбом.

## Публічний сайт

- [ ] Головна `/products` — картки, фільтри, пагінація
- [ ] Картка товару — галерея, вибір розміру, «Додати в кошик»
- [ ] Відео в картці — автопрогравання, без кнопки завантаження
- [ ] Меню (☰) — всі пункти, кошик, вподобання, замовлення
- [ ] Кошик — зміна кількості, перехід до checkout
- [ ] Checkout — телефон `099...` → `+380...`, самовивіз, НП
- [ ] Реєстрація / логін на checkout
- [ ] Лист після замовлення (перевір пошту)
- [ ] Сторінка «Про нас»

## Панель менеджера (staff)

- [ ] Горизонтальне меню зверху (мобільний)
- [ ] Дашборд — картки виторгу, клік на звіт
- [ ] Замовлення — таблиця з горизонтальним скролом, зміна статусу
- [ ] Товари — список, створення/редагування
- [ ] Звіти — таблиця, завантаження XLSX

## Відомі покращення в коді

- Горизонтальна навігація менеджера на `< md`
- `overflow-x-auto` для таблиць
- Зменшені відступи на малих екранах
