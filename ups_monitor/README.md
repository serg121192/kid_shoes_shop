# Delta UPS — SNMP моніторинг

Простий Python-скрипт для віддаленого опитування UPS Delta через **SNMPv1** (MIB `DeltaUPS-MIB`).

## Що знімає

| Параметр | OID | Примітка |
|---|---|---|
| Вхідна напруга | `1.3.6.1.4.1.2254.2.4.4.3.0` | дільник 10 → Вольти |
| Температура | `1.3.6.1.4.1.2254.2.4.7.9.0` | °C |
| Джерело живлення | `1.3.6.1.4.1.2254.2.4.5.1.0` | `0` = мережа |
| Заряд батареї | `1.3.6.1.4.1.2254.2.4.7.8.0` | % |

## Встановлення

```bash
cd ups_monitor
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Використання

```bash
# Текстовий вивід
python ups_status.py 192.168.1.50 -c public

# JSON
python ups_status.py 192.168.1.50 -c mycommunity --json
```

Приклад виводу:

```
UPS 192.168.1.50
  Вхідна напруга : 230.5 V
  Температура    : 28 °C
  В мережі       : так (мережа)
  Заряд батареї  : 100 %
```

## Налаштування на UPS

У веб-інтерфейсі SNMP-карти (InsightPower):

1. Увімкніть **SNMPv1 Access Protocol**
2. Вкажіть community string
3. Дозвольте IP машини, з якої запускаєте скрипт
4. Порт SNMP: **UDP 161**

> Якщо OID не відповідають (інша карта/прошивка), зробіть `snmpwalk -v1 -c public <IP> 1.3.6.1.4.1.2254.2.4` і підставте актуальні значення в `OIDS` у скрипті.
